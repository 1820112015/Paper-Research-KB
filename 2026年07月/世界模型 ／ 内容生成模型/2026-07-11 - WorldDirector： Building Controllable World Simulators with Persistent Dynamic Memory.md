# WorldDirector: Building Controllable World Simulators with Persistent Dynamic Memory

**收录日期：** 2026-07-11  
**分类：** 世界模型 / 内容生成模型

## 摘要

WorldDirector 将语义运动编排与像素生成解耦：先由大语言模型联合规划物体三维轨迹和相机运动，再把轨迹作为视频生成条件。它重点解决动态物体离开视野后再次出现时的身份保持问题，从而支持长程事件、自由视角探索和持久动态记忆。

**关键词：** 视频世界模型、动态物体记忆、轨迹控制、视角探索、长期一致性
