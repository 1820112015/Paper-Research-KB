# WildWorld: A Large-Scale Dataset for Dynamic World Modeling with Actions and Explicit State toward Generative ARPG

**收录日期：** 2026-07-09  
**分类：** 理论与标准研究

## 摘要

WildWorld 从《怪物猎人：荒野》自动采集超过一亿帧动作条件数据，覆盖 450 余种动作，并同步标注骨骼、世界状态、相机位姿和深度。配套 WildBench 从动作跟随和状态对齐评估模型，强调显式状态对学习长程、结构化世界动力学的重要性。

**关键词：** 世界模型数据集、动作条件、显式状态、ARPG、基准评测
