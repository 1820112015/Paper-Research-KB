# Beyond Borrowed Histories: Person-Aligned User Simulation for Interactive Role-Playing Evaluation

**收录日期：** 2026-08-05

**分类：** 多智能体+LLM

## 摘要

该工作提出 Palate 评测框架，用真实多轮对话和同步体验标注构建个性化用户模拟器，避免传统角色扮演评测让模型延续“借来的历史”而导致能力评估失真。它通过 per-user LoRA 对齐用户模拟器，并从个性化体验、通用回合质量和整体会话质量三个维度评价角色扮演智能体，更适合衡量长期互动中的真实用户体验。

**关键词：** 角色扮演智能体、用户模拟器、个性化评测、per-user LoRA、多轮交互、RPA评测
