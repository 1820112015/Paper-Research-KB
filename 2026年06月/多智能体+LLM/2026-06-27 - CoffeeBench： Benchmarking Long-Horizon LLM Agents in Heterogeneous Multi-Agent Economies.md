# CoffeeBench: Benchmarking Long-Horizon LLM Agents in Heterogeneous Multi-Agent Economies

**收录日期：** 2026-06-27

**分类：** 多智能体+LLM

## 摘要

CoffeeBench 把六家大模型公司放入异构咖啡供应链中连续经营 90 天，评估长程规划、谈判、库存和利润管理。基准让被测模型控制一家烘焙商，其余农场、烘焙商和零售商由参考智能体运行，从而观察多智能体经济中的策略适应与系统性后果。

**关键词：** 大模型智能体、多智能体经济、供应链模拟、长程决策、基准评测
