# MemoryWAM: Efficient World Action Modeling with Persistent Memory

**收录日期：** 2026-06-29  
**分类：** 记忆系统

## 摘要

MemoryWAM 为世界动作模型设计短期窗口、长期摘要和事件边界相结合的持久混合记忆。该机制避免全量 KV 缓存随轨迹增长带来的显存与延迟开销，同时保留跨长程任务所需的历史信息，使机器人控制在效率和记忆完整性之间取得更实用的平衡。

**关键词：** 世界动作模型、混合记忆、持久记忆、机器人控制、高效推理
