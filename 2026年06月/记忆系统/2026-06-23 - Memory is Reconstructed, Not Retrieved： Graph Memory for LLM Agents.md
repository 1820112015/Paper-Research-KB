# Memory is Reconstructed, Not Retrieved: Graph Memory for LLM Agents

**收录日期：** 2026-06-23  
**分类：** 记忆系统

## 摘要

MRAgent 把长期记忆表示成“线索—关系标签—内容”图，并把大模型推理嵌入记忆访问过程。智能体可根据中间证据动态扩展、收缩和重组相关记忆，而不是一次检索后固定推理，从而提升跨长交互历史的复杂问答表现。

**关键词：** 智能体记忆、记忆图、主动重构、长上下文推理、大语言模型
