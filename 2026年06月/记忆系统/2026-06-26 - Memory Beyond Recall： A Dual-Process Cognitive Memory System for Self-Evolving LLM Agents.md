# Memory Beyond Recall: A Dual-Process Cognitive Memory System for Self-Evolving LLM Agents

**收录日期：** 2026-06-26

**分类：** 记忆系统

## 摘要

DCPM 将智能体长期记忆设计为双过程认知系统：快速过程持续记录经历，慢速过程异步抽象跨事件模式并更新认知结构。系统保留事实与偏好的演化链，而不是简单覆盖旧记忆，使智能体能够处理隐式个性化、信念变化和跨会话推理。

**关键词：** 长期记忆、双过程认知、自我演化智能体、信念更新、个性化
