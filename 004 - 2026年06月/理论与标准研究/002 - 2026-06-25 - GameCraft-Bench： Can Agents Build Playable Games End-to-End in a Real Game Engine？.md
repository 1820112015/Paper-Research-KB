# GameCraft-Bench: Can Agents Build Playable Games End-to-End in a Real Game Engine?

**收录日期：** 2026-06-25

**分类：** 理论与标准研究

## 摘要

GameCraft-Bench 要求编程智能体在真实 Godot 引擎中从零交付可启动、可操作的完整二维游戏，并通过回放验证可玩性。它把任务分解为代码、视觉、交互和游戏性等维度，揭示当前智能体即使能生成项目，也常在端到端完成度和实际可玩性上失败。

**关键词：** 编程智能体、游戏开发、Godot、端到端评测、基准
