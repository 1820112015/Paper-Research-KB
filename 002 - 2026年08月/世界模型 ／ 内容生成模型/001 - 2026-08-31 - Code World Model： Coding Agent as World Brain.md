# Code World Model: Coding Agent as World Brain

**收录日期：** 2026-08-31

**分类：** 世界模型 / 内容生成模型

## 摘要

把世界演化与视觉渲染拆开：编码 Agent 充当“世界大脑”，用可执行代码维护实体、关系和规则一致的持久状态；轻量编译器把状态转为逐帧时空约束的代理视频，再由视频模型补全高保真视觉，并建立游戏与现实视频的代理—观测配对管线。在配对游戏数据上微调后，MiniMax-H3 能够遵循编码 Agent 构建的简单交互世界及其时空规格，同时保留细节与运动。贡献偏概念验证：代码负责“世界为什么这样变”，生成模型负责“变化长什么样”，为开放式、可持续演化的世界模型提供新路线；局限在于仅验证简单世界，代码规则质量受 LLM 推理能力限制。

**关键词：** 代码世界模型、编码Agent、世界大脑、代理视频、状态一致性、开放式世界模型
