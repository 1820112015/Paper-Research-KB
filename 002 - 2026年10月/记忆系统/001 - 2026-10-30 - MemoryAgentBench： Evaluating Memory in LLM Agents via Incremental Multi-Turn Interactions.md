# MemoryAgentBench: Evaluating Memory in LLM Agents via Incremental Multi-Turn Interactions

**收录日期：** 2026-10-30

**分类：** 记忆系统

## 摘要

MemoryAgentBench（ICLR 2026）是面向记忆智能体的统一评测基准：把记忆科学的四维能力（准确检索、测试时学习、长程理解、选择性遗忘）、增量多轮交互协议与三类智能体范式整合进同一框架，覆盖长上下文模型、RAG 与 Agentic 记忆共 22 个配置。结论是四维能力没有系统能同时掌握，选择性遗忘是集体短板。

**关键词：** 智能体记忆、记忆评测、增量多轮、长上下文、知识编辑
