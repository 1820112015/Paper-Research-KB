# ANTE: Anticipate, Then Execute — Learning Internal World Models for Coding Agents from Verified Beliefs

**收录日期：** 2026-10-28

**分类：** 理论与标准研究

## 摘要

ANTE（2026.10，AWS AI Labs / UMD）让 coding agent 动手前先预测测试结果，再用真实执行校验这些“已验证信念”，并以 RL 联合训练内部世界模型与 policy，减少难以追溯的坏编辑；SWE-bench Verified 57.2%。

**关键词：** coding agent、内部世界模型、动作预判、RL、SWE-bench
