# WebWorld: The Browser as a World Model for Self-Improving Web Code

**收录日期：** 2026-10-28

**分类：** 理论与标准研究

## 摘要

VLM 自己提修复、自己评判时，网页“看着对”不等于真的能用。WebWorld 把浏览器当作世界模型重新执行改动、只保留真正修好的 diff 做 SFT，MiniAppBench 提升 14.9（2026.08）。

**关键词：** 网页代码、世界模型、自我改进、浏览器执行、SFT
