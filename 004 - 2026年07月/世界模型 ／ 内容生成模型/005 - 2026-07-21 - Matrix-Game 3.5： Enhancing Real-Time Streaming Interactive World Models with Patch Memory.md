# Matrix-Game 3.5: Enhancing Real-Time Streaming Interactive World Models with Patch Memory

**收录日期：** 2026-07-21

**分类：** 世界模型 / 内容生成模型

## 摘要

Matrix-Game 3.5 在 Matrix-Game 3.0 基础上引入面向几何的长程记忆和实时蒸馏，以实现 720p、分钟级的交互式世界生成。Patch Memory 把历史观测提升为带三维几何对齐的局部补丁，Warped PRoPE 将相机投影几何注入时空旋转位置编码，从而统一长期记忆与相机控制。模型还通过 Self-Rollout DMD 将双向扩散模型逐步蒸馏为少步因果生成器。

**关键词：** 交互式世界模型、Patch Memory、几何记忆、实时流式生成、相机控制、长时一致性
