# Matrix-Game 3.0: Real-Time and Streaming Interactive World Model with Long-Horizon Memory

**收录日期：** 2026-07-01

**分类：** 世界模型 / 内容生成模型

## 摘要

Matrix-Game 3.0 通过工业级数据引擎、误差感知训练和相机相关记忆，解决交互式视频世界模型的长期一致性问题。多段自回归蒸馏、量化和轻量 VAE 解码器把 5B 模型推进到 720p、最高 40 FPS，并能维持分钟级记忆。

**关键词：** 交互式世界模型、长期记忆、实时生成、自我纠错、流式视频
