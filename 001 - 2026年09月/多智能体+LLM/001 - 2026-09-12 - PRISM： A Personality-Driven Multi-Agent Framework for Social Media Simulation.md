# PRISM: A Personality-Driven Multi-Agent Framework for Social Media Simulation

**收录日期：** 2026-09-12

**分类：** 多智能体+LLM

## 摘要

把人格建模引入 LLM 社会模拟：PRISM（Personality-Refracted Intelligent Simulation Model）用 16 个异构 LLM 智能体承载不同 MBTI 人格类型，以多话题社交媒体评论数据为输入，经情绪与情感评分驱动智能体反应，模拟观点碰撞与情绪积累的过程，用于预测网络争吵如何升级等社交媒体动力学。人格充当“折射”视角——不同性格的智能体对同一讨论产生差异化反应，从而比同质智能体更真实地复现群体讨论的演化与冲突升级。

**关键词：** 社会模拟、人格建模、多智能体、MBTI、LLM智能体、冲突升级预测、情绪分析
