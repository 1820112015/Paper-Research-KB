# MMA: Multimodal Memory Agent

**收录日期：** 2026-10-25

**分类：** 记忆系统

## 摘要

MMA 关注相似度检索常翻出过期、低可信或相互矛盾的记忆、从而诱发过度自信错误的问题：为每条记忆计算动态可信度（来源可信度 + 时间衰减 + 冲突感知共识），据此重加权，证据不足时选择弃答；并构建 MMA-Bench 揭示多模态记忆中的“视觉安慰剂效应”（2026.02）。

**关键词：** 多模态记忆、动态可信度、冲突感知、弃答机制、记忆重加权、MMA-Bench
