# GraphMemix: Query-Aware Evidence Forests for Long-Term Multimodal Agent Memory

**收录日期：** 2026-10-25

**分类：** 记忆系统

## 摘要

GraphMemix 针对长程多模态智能体记忆的两个痛点——离线总结全部历史太贵且易丢关键视觉细节、相似度检索偏爱近重复而漏掉互补证据——把“选记忆”改造成问题到来后的组合优化：先扩出有界候选子图，给节点估支持度、给边校验是否互补，再在预算内用 Kruskal 求最大权重“证据森林”喂给冻结模型。四个基准上平均提升 11.75 分（2026.08，PKU + MemoraX AI）。

**关键词：** 智能体记忆、证据森林、查询感知检索、多模态长程记忆、组合优化、Kruskal
