# DG-Mem: Dual-Grained Agent Memory and Shapley Context Attribution for Multimodal Agentic Learner

**收录日期：** 2026-10-25

**分类：** 记忆系统

## 摘要

DG-Mem 解决闭源/端侧模型无法改参数、而无状态提示又丢掉“已解过的题”复利收益的问题：给冻结模型外挂只读记忆，分“实例样例”与“类别 IF-THEN 规则”两种粒度，规则只从反思中合成；检索时用 Shapley 值对规则逐条做信用分配，替代纯相似度排序（2026.08）。

**关键词：** 双粒度记忆、Shapley值、上下文归因、多模态智能体、规则合成、冻结模型
