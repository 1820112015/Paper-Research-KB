# WorldCast: Exploring Intelligent Visual Generation in World State Prediction

**收录日期：** 2026-10-25

**分类：** 理论与标准研究

## 摘要

WorldCast 是一个多步生成基准，用 320 个任务、8 类场景检验生成系统能否在复杂多模态上下文（当前观察、目标状态、规则、物理属性、操作示范）中判断“信息该在哪一步使用”，并产出符合真实规律的连续世界状态，典型任务如机械臂完成具身操作、组装椅子或积木。作者对比 12 个图像侧统一生成理解模型与多个视频生成系统：前沿统一模型已显露初步世界状态预测能力，GPT-Image-2.5 达 72.8 分，甚至超过 Seedance 这类天然刻画多步状态的视频模型，其余系统多数难及格；复杂参考、相互交织的约束与多步推理是主要瓶颈。分析显示视觉侧的时序因果能力与语言侧的文本智能都显著影响成绩（替换 GPT-Image 的文本模型会明显改变得分），而具备 Agent 能力的模型可借 Coding + Agentic Loop 把规划与推演外化成视觉参考，从而提升表现。

**关键词：** 世界状态预测、多步生成、统一多模态、benchmark、具身操作、Agentic Loop
